# vinext app

This project was created with create-vinext-app.

## Scripts

- `pnpm run dev` starts the vinext dev server.
- `pnpm run build` builds the Cloudflare Worker output.
- `pnpm run start` serves the built Worker locally (`vite preview`).
- `pnpm run deploy` builds and deploys the Cloudflare Worker described in `cloudflare.config.ts`.
