# Montara Pass mobile

The native app: Expo (SDK 58) with expo-router on React Native 0.88 / React
19. Screens mirror the web app's routes in `apps/app` as placeholders and are
migrated to native one at a time (the `expo-web-to-native` skill holds the
migration order).

## Scripts

- `pnpm run dev` starts Metro (`expo start`); press `i` for the iOS simulator,
  `a` for the Android emulator, or scan the QR code with Expo Go.
- `pnpm run typecheck` runs `tsc --noEmit`.

## Layout

- `src/app`: file-based routes. The `(auth)` and `(app)` groups mirror the web
  app's groups; typed routes are enabled (`experiments.typedRoutes`).
- `src/components`, `src/constants`, `src/hooks`: the rest of the app. `@/`
  points at `src/`.

There are no `ios/` or `android/` directories: they are generated by prebuild
(Continuous Native Generation). Configure native behavior in `app.json` and
config plugins, never by hand.

## Notes

- `@montara-pass/shared` is linked as a dependency, but the vault crypto does
  not run on Hermes yet (`hash-wasm` needs WebAssembly). Wiring the data layer
  happens when the first screens migrate.
- Icons, splash and branding are still the create-expo-app placeholders.
