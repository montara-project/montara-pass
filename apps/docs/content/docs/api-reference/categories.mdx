---
title: Categories
description: A plain, unencrypted reference list managed by super users.
---

Categories are not part of the encrypted vault. Reading them is public;
writing needs a signed-in user with the `super_user` role.

| Method and path | Access | Purpose |
| --- | --- | --- |
| `GET /v1/categories` | public | List, with `offset`, `limit`, `search` and `sorted` |
| `GET /v1/categories/:id` | public | One category |
| `POST /v1/categories` | super user | Create |
| `PUT /v1/categories/:id` | super user | Rename |
| `DELETE /v1/categories/:id` | super user | Move to the trash |
| `PUT /v1/categories/:id/restore` | super user | Bring back |
| `DELETE /v1/categories/:id/force` | super user | Delete permanently |

## Body

```json
{ "name": "Work" }
```

`name` is required and at most 100 characters.

## List parameters

- `search`: a case-insensitive match on the name, at most 100 characters.
- `sorted`: a column and a direction, such as `name:asc`. The columns are
  `name`, `created_at` and `updated_at`; the default is `created_at:desc`.
